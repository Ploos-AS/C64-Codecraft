# Credits, licenses and provenance
Scene culture values credit, and a public source repository also needs clear legal provenance.

For every third-party contribution or asset record:
- author/handle;
- source;
- license or explicit permission;
- modifications;
- where it is used;
- required credit text when applicable.

Do not copy music, graphics, code or ROM material into the repository merely because it is easy to find online.

## Credits are architecture
Plan credits early. Musician, graphician, coder and tool contributions should not become an afterthought at release time.

## Scene connection
**Why does a demo coder care about this?**
Correct attribution is part of scene practice and makes an open educational production safer to study, fork and redistribute.

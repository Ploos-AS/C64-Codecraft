# Production craft and scene workflow
Technical effects are only part of making a credible release. This block develops the workflow around them: source organization, real scene tools, assembler dialect literacy, debugging, asset provenance, credits and release preparation.

Codecraft remains editor-independent and assembler-first. Tools support the work; they do not become the programming model.

# Release craft
A finished binary still needs a clear release package.

Prepare:
- production title and version;
- credits;
- target machine/video-standard notes;
- controls or exit behaviour if relevant;
- disk/program filenames;
- build/reproduction instructions;
- known limitations;
- screenshots or capture material where legally appropriate;
- hashes for release artifacts where useful.

If submitting to a party or archive, follow that event/archive's current rules rather than assuming one universal scene convention.

## Do not optimize away clarity
A tiny on-disk release can coexist with a well-documented source repository. The public educational project should preserve the explanation even when the final binary is aggressively packed.

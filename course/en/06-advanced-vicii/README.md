# Advanced VIC-II techniques
This block studies effects that depend on the VIC-II's fetch schedule, sprite DMA and precisely timed register changes.

These are model-sensitive techniques. Every executable lab must name its target VIC-II/video standard and explain the timing it relies on. We learn mechanisms, not unexplained magic constants.

# Capstone — From Zero to Demo Coder
Build and release an original C64 production.

There is no Codecraft framework and no single prescribed effect list. Your job is to make technical and artistic constraints agree, then prove that the result builds and runs as intended.

The capstone should demonstrate fundamentals, hardware understanding, timing, integration, optimization and production craft—not merely copy isolated routines.

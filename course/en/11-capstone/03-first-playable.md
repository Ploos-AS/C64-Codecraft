# First playable build
Create an ugly but complete path through the production.

It should boot, initialize required systems, enter every planned part, perform placeholder transitions and reach the ending. If multipart, prove the loading path now.

Use placeholder graphics/music only when they are legal and clearly marked; simple generated test assets are often better.

## Why so early?
An end-to-end skeleton exposes architectural failures while individual effects are still cheap to change.

## Gate
A clean checkout can build and run through the complete structural sequence without manual patching.

## Next
Replace placeholders with authored assets and real effect work.

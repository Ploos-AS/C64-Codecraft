# Ship the demo
Create the final release from a clean, identified source revision.

The release package should contain the intended C64 artifact(s) and clear metadata. The repository should contain enough source, legal assets, build instructions, credits and technical documentation for another coder to study and reproduce it.

Record release hashes where practical and tag the source revision.

If submitting to an event or archive, check its current requirements separately.

## Final rule
Do not make last-minute unmeasured code changes after qualification. If code changes, qualification changes.

## Gate
A third party can identify the release, its authors/credits, target, source revision and reproduction procedure.

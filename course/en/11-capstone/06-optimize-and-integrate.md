# Optimize the integrated production
Now optimize the production that actually exists.

Capture worst-case timing and memory pressure for each critical part. Use the optimization log method from Course 8. A change must solve a stated constraint and must survive regression testing.

Possible tools include better scheduling, zero-page placement, precalculation, unrolling, SMC, packing or—when justified and qualified—an undocumented opcode.

## Protect the production
Do not sacrifice stable transitions, music cadence or maintainability for cycle savings the effect does not need.

## Gate
All critical frame windows have margin or a documented exact-fit requirement, and no unresolved memory ownership conflicts remain.

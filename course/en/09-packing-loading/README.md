# Packing, loading and multipart demos
A production larger than one resident part needs another kind of engineering: data must be stored, loaded, unpacked and handed between parts without violating memory or timing contracts.

This block starts with transparent offline packing and disk images, then moves toward loaders and multipart architecture. Tool choice remains replaceable; the formats, constraints and interfaces must be understood.

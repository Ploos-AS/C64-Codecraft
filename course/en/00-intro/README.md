# Welcome to C64 Codecraft

The goal is simple: start with no machine-code assumptions and finish able to reason about, build and debug real Commodore 64 demo code.

You will use real assemblers and a real C64 emulator. The course tooling helps automate repetitive work, but it will not hide the machine from you.

## First milestone

Your first programs will establish a deterministic build-and-run loop. From there we move into the 6510 itself.

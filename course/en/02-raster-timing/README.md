# Raster timing and interrupts

This block changes the question from **what does the code do?** to **exactly when does it do it?**

We study the VIC-II raster beam, PAL/NTSC differences, raster registers, interrupts, cycle budgets, badlines and the path toward stable raster effects.

Scene rule: timing claims must be measured or derived for the target machine model. PAL and NTSC are not interchangeable constants.

# Smooth scrolling
This block combines VIC-II fine scrolling, coarse screen-memory updates, streamed text, colour and raster scheduling into a real smooth scroller.

The goal is not a library call. We build the mechanism from registers, bytes and cycles, then evolve it toward scene-style motion.

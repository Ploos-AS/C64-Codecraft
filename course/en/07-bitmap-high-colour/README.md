# Bitmap and high-colour graphics
This block moves from character graphics to bitmap display and then to timing-driven high-colour techniques.

We keep three things separate: the VIC-II display representation, the offline asset pipeline, and the runtime raster code. Scene tooling may generate data, but the student must understand what the generated bytes mean.

# SID music and synchronization
This block adds sound to the frame plan. We learn enough SID hardware to understand what the machine is doing, then use real music-player interfaces without turning Codecraft into an audio framework.

The scene goal is integration: music playback, raster timing and visual effects sharing one machine and one cycle budget.

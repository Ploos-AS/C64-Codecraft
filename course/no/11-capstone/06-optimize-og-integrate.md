# Optimize den integrerte produksjonen
Optimaliser nå produksjonen som faktisk finnes.

Registrer worst-case timing og memory pressure for hver critical part. Bruk optimization-log-metoden fra Course 8. En endring skal løse en oppgitt constraint og overleve regression testing.

Mulige tools er bedre scheduling, zero-page placement, precalculation, unrolling, SMC, packing eller — når begrunnet og kvalifisert — undocumented opcode.

## Beskytt produksjonen
Ikke ofre stable transitions, music cadence eller maintainability for cycle savings effekten ikke trenger.

## Gate
Alle critical frame windows har margin eller dokumentert exact-fit requirement, og ingen unresolved memory ownership conflicts gjenstår.

## Neste
Definer og test video-standard/hardware policy.

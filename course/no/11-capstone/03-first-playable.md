# First playable build
Lag en stygg, men komplett path gjennom produksjonen.

Den skal boote, initialisere nødvendige systems, gå innom alle planlagte parts, utføre placeholder transitions og nå ending. Hvis multipart skal loading path bevises nå.

Bruk placeholder graphics/music bare når de er lovlige og tydelig merket; enkle generated test assets er ofte bedre.

## Hvorfor så tidlig?
Et end-to-end skeleton avslører architecture failures mens individuelle effects fortsatt er billige å endre.

## Gate
Clean checkout kan bygge og kjøre gjennom komplett structural sequence uten manual patching.

## Neste
Erstatt placeholders med authored assets og virkelig effect-arbeid.

# Capstone — From Zero to Demo Coder
Bygg og release en original C64-production.

Det finnes ikke noe Codecraft-framework og ingen obligatorisk liste med bestemte effects. Oppgaven er å få tekniske og kunstneriske constraints til å passe sammen og deretter bevise at resultatet bygger og kjører som planlagt.

Capstone skal demonstrere fundamentals, hardware-forståelse, timing, integration, optimization og production craft — ikke bare kopiere isolerte routines.

# Concept og scope
Start med en production-idé, ikke en technology checklist.

Skriv one-page brief med:
- title/working title;
- visual og musical direction;
- intended duration;
- target machine/video standard;
- one-file eller multipart structure;
- major parts/transitions;
- effects som tjener konseptet;
- asset authorship/provenance plan;
- technical risks;
- en bevisst liten minimum shippable version.

## Scene-kobling
**Hvorfor bryr en demo-koder seg om dette?**
Det beste tekniske trikset kan ikke redde en production der scope aldri konvergerer.

## Gate
Ikke start final implementation før minimum release kan beskrives tydelig.

## Neste
Gjør konseptet om til frame-, memory- og part-architecture.

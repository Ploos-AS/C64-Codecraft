# Demo-koder postmortem
Etter release skriver du engineering story.

Svar på:
- Hvilken assumption var mest feil?
- Hvilken effect eller subsystem krevde mest iteration?
- Hvor endret cycle counting designet?
- Hvilken memory trade-off betydde mest?
- Hva avslørte debugger som visual testing ikke viste?
- Hva ville du architect annerledes neste gang?
- Hvilken teknikk forstår du nå godt nok til å forklare uten source code?

Ta med målte before/after-eksempler der nyttig.

## Siste kontrollpunkt
Du startet med bytes, addresses og `LDA`/`STA`. Nå kan du resonnere om 6510, VIC-II, SID, raster timing, assets, loaders, optimization og release engineering som ett production system.

Kurset sertifiserer ikke at du er del av noe scene-community. Det gir deg technical foundation til å lage arbeid, release det, lære av andre og fortsette å bli bedre.

## Fortsett
Les ekte productions. Bygg små effects. Delta på eller følg demo-events. Krediter folk riktig. Mål koden. Release ting.

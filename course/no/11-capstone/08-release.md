# Ship demoen
Lag final release fra en clean, identifisert source revision.

Release package skal inneholde intended C64 artifact(s) og tydelig metadata. Repository skal inneholde nok source, lovlige assets, build instructions, credits og technical documentation til at en annen coder kan studere og reprodusere den.

Registrer release hashes der praktisk og tag source revision.

Ved submission til event eller archive sjekkes deres aktuelle krav separat.

## Siste regel
Ikke gjør last-minute unmeasured code changes etter qualification. Hvis code endres, endres qualification.

## Gate
En tredjepart kan identifisere release, authors/credits, target, source revision og reproduction procedure.

## Neste
Skriv postmortem: hva lærte du som demo-koder?

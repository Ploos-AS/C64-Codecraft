# Velkommen til C64 Codecraft

Målet er enkelt: Vi starter uten å forutsette erfaring med maskinkode, og ender med at du kan forstå, bygge og feilsøke ekte Commodore 64 demokode.

Du skal bruke ekte assemblere og en ekte C64-emulator. Kursverktøyene automatiserer kjedelig arbeid, men skjuler ikke maskinen.

## Første milepæl

De første programmene etablerer en deterministisk bygg-og-kjør-løkke. Derfra går vi inn i selve 6510-prosessoren.

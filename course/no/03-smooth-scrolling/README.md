# Smooth scrolling
Denne blokken kombinerer VIC-II fine scrolling, coarse screen-memory updates, text stream, colour og raster scheduling til en virkelig smooth scroller.

Målet er ikke et library call. Vi bygger mekanismen fra registers, bytes og cycles og utvikler den videre mot scene-style movement.

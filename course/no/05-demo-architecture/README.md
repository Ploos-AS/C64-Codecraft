# Demo architecture
Nå slutter vi å behandle effects som isolerte øvelser. En demo-part må få graphics, music, timing, memory og transitions til å sameksistere.

Målet er en liten, men virkelig scene-style part bygget av vanlig 6510 assembly og eksplisitte data. Ingen Codecraft-runtime introduseres.

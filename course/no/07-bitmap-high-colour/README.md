# Bitmap og high-colour graphics
Denne blokken går fra character graphics til bitmap-display og videre til timing-driven high-colour techniques.

Vi holder tre ting separate: VIC-II display representation, offline asset pipeline og runtime raster code. Scene-tools kan generere data, men eleven skal forstå hva de genererte bytes betyr.

# Raster timing og interrupts

Denne blokken endrer spørsmålet fra **hva gjør koden?** til **nøyaktig når gjør den det?**

Vi studerer VIC-II raster beam, PAL/NTSC-forskjeller, raster-registre, interrupts, cycle budgets, badlines og veien mot stabile rastereffekter.

Scene-regel: timing-påstander skal måles eller utledes for målmaskinen. PAL og NTSC er ikke utskiftbare konstanter.

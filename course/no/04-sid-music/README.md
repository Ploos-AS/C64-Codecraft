# SID music og synchronization
Denne blokken legger lyd inn i frame-planen. Vi lærer nok SID-hardware til å forstå hva maskinen gjør, og bruker deretter reelle music-player interfaces uten å gjøre Codecraft til et audio-framework.

Scene-målet er integration: music playback, raster timing og visuelle effekter deler samme maskin og cycle budget.

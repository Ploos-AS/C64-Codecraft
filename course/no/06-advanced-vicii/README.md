# Advanced VIC-II techniques
Denne blokken studerer effects som avhenger av VIC-II fetch schedule, sprite DMA og presist timede registerendringer.

Dette er model-sensitive teknikker. Hver executable lab skal navngi target VIC-II/video standard og forklare timingen den bygger på. Vi lærer mekanismer, ikke uforklarte magic constants.

# Release craft
En ferdig binary trenger fortsatt en tydelig release package.

Forbered:
- production title og version;
- credits;
- target machine/video-standard notes;
- controls eller exit behaviour der relevant;
- disk/program filenames;
- build/reproduction instructions;
- known limitations;
- screenshots eller capture-material der det er lovlig;
- hashes for release artifacts der nyttig.

Ved submission til party eller archive følges aktuelle regler for event/archive i stedet for å anta én universell scene convention.

## Ikke optimaliser bort clarity
En liten on-disk release kan sameksistere med et godt dokumentert source repository. Det offentlige educational project skal bevare forklaringen selv om final binary er aggressivt packed.

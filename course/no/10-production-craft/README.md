# Production craft og scene workflow
Tekniske effects er bare en del av en troverdig release. Denne blokken utvikler workflow rundt dem: source organization, ekte scene-tools, assembler dialect literacy, debugging, asset provenance, credits og release preparation.

Codecraft forblir editor-independent og assembler-first. Tools støtter arbeidet; de blir ikke programming model.

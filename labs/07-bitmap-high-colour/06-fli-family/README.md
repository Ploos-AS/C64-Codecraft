# Lab 07.06 — FLI-family tradeoff matrix

## Goal
Compare high-colour techniques by explicit resource contracts instead of treating “FLI” as one implementation.

The starter stores compact descriptors for four teaching candidates. Each descriptor records relative memory, timing sensitivity and flexibility classes. The numbers are labels for comparison exercises, not benchmark claims.

## Exercise
Using the lesson and external technical references, replace the teaching labels with your own documented matrix for the exact techniques you intend to use.

Include:
- colour freedom,
- memory footprint,
- CPU/raster cost,
- side effects,
- conversion/tool requirements,
- PAL/NTSC or VIC-II assumptions.

**Why does a demo coder care?** Choosing a graphics mode is an engineering tradeoff tied to the production, not a prestige ladder.

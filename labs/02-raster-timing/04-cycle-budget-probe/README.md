# Lab 02.04 — Cycle-budget probe

Use the border as an oscilloscope-like marker around a known block of CPU work.

The exact visible width depends on video timing and surrounding execution; the point is to compare versions, not memorize an unexplained number.

Modify the work block and compare the border pulse.

**Why does a demo coder care?** Raster code must fit deadlines. Measurement turns “fast enough” into an observable budget.

# Lab 10.07 — Production review gate

## Goal
Review a production as an integrated system before calling it finished.

The starter models seven review gates in RAM. Replace each teaching value with evidence from your production.

## Review gates
1. build reproducibility,
2. memory/ZP ownership,
3. raster/timing qualification,
4. music/effect/loader coexistence,
5. asset provenance,
6. PAL/NTSC and hardware assumptions,
7. release artifact verification.

A gate is not complete because the code “seems to work”; link it to a measurement, test, document or known limitation.

**Why does a demo coder care?** Production quality is what remains after individually impressive effects are forced to coexist in a release.

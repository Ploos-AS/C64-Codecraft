# Lab 10.01 — Production project layout

## Goal
Turn a one-file experiment into a production whose code, assets, generated files and release artifacts have clear ownership.

The starter remains deliberately small. Create a project map that distinguishes:
- hand-written source,
- source artwork/music,
- generated binary assets,
- build output,
- release output,
- documentation and qualification notes.

Generated artifacts should be reproducible and should not become accidental sources of truth.

**Why does a demo coder care?** Once a production has multiple parts and contributors, directory structure becomes part of the engineering interface.

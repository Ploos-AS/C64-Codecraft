# Lab 10.04 — Scene-tool integration

## Goal
Treat external scene tools as explicit, reproducible stages in the production pipeline.

The starter uses embedded teaching data so it always builds. Replace one asset with output from a real graphics or music tool and document:
- source format,
- tool/version,
- export settings,
- conversion command if any,
- binary layout/load address,
- license/provenance.

GUI tools may remain host-native; the course does not require hiding them behind a Codecraft framework.

**Why does a demo coder care?** Art, music and code become one demo only when their binary contracts agree.

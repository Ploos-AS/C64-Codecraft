# Lab 10.05 — Credits and provenance

## Goal
Make authorship, source and reuse terms part of the production data.

The executable stays tiny; the real lab is the provenance record. For every external asset, code fragment, tune, conversion tool or reference implementation used by your production, record:
- creator/source,
- original location or release,
- license/reuse permission,
- modifications,
- required credit text,
- where it appears in the release.

Do not commit material whose redistribution rights are unclear merely because it is common in scene archives.

**Why does a demo coder care?** Scene culture depends on attribution and lineage as much as technical craft; a reproducible build also needs reproducible provenance.

# Lab 05.06 — Part transitions

## Goal
Treat a transition as owned state between two parts rather than an abrupt jump.

The starter runs three phases: part A, a short transition, then part B. Each phase has explicit update/render routines and a single phase variable.

## Modify
Replace the border-colour transition with a table-driven fade or wipe using techniques already learned.

**Why does a demo coder care?** Production quality often lives between effects. Transitions need timing, state and memory ownership too.

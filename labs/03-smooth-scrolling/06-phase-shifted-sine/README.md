# Lab 03.06 — Phase-shifted sine data

## Goal
Generate several related positions from one lookup table by adding different phase offsets.

The starter writes eight table-derived values to $c000-$c007 so the pattern can be inspected without tying the concept to one renderer.

Change the phase spacing and table values, then predict the output before running.

**Why does a demo coder care?** Phase-shifted lookup tables are a cheap way to create waves, trails and coordinated motion.

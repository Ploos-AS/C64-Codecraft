# Lab 06.04 — Line-crunch preparation probe

## Goal
Build the measurement harness needed before experimenting with line crunching.

A fresh raster transition produces a short border marker and snapshots $D011. The lab deliberately stops before a cycle-sensitive crunch sequence.

Use VICE stepping to identify the intended control-write window and document every machine assumption.

**Why does a demo coder care?** Advanced VIC-II tricks are timing experiments first and reusable techniques only after qualification.

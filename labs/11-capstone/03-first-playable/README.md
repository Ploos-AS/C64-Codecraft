# Lab 11.03 — First playable build

## Goal
Create the earliest complete vertical slice.

A first playable should boot, initialize, run one visible effect, advance one music/sync state and reach a defined exit/transition condition. Quality comes later; the whole path must exist first.

The teaching starter uses a frame counter, border effect and coarse sync state. Replace these pieces with your actual production while preserving the end-to-end path.

**Why does a demo coder care?** Integration risk is discovered earlier by a rough complete slice than by polishing isolated effects.

# Lab 11.04 — Effects and assets integration

## Goal
Integrate one real effect with its real asset contract.

The starter combines a table-driven visual state with a small embedded teaching asset. Replace the asset with reproducible output from your chosen graphics workflow and connect it to the signature effect.

Record provenance, conversion steps, load addresses and memory ownership.

**Why does a demo coder care?** An effect is production code only after the actual art/data pipeline fits its timing and memory model.

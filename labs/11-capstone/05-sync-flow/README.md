# Lab 11.05 — Sync and flow

## Goal
Make progression through the demo intentional.

The starter converts a monotonically increasing music/event tick into four coarse cues and uses those cues to select visual state. Your production should replace the synthetic tick with the real music/sync contract.

Document why each transition happens and which state must be restored or handed to the next part.

**Why does a demo coder care?** A demo is more than effects in sequence; timing, anticipation and transitions create the production's flow.

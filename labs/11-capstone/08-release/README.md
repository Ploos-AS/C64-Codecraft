# Lab 11.08 — Capstone release

## Goal
Produce the artifact that another scener can run and verify.

Freeze a release candidate and record:
- source revision/tag,
- exact build environment,
- PRG/D64 artifacts,
- sizes and checksums,
- credits and provenance,
- target hardware/video standard,
- run instructions,
- known limitations,
- qualification evidence.

Do not repair the release artifact manually after the reproducible build. Fix source/build inputs and rebuild.

The starter carries a visible release signature that can be inspected in memory.

**Why does a demo coder care?** The release is the production. Source quality matters, but the audience experiences the bytes you ship.

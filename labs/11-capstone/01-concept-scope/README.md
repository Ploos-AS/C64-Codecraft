# Lab 11.01 — Capstone concept and scope

## Goal
Define a demo you can actually finish.

Write a one-page production brief covering:
- concept/mood,
- target audience/release context,
- minimum set of parts,
- one signature effect,
- graphics/music needs,
- target machine/video standards,
- release format,
- explicit non-goals.

The starter is only a project heartbeat. Replace it gradually; do not begin by building infrastructure that is unrelated to the concept.

**Why does a demo coder care?** Scope is a technical constraint. A finished focused demo teaches more than an endless engine project.

# Lab 08.01 — Measure before optimizing

## Goal
Establish a baseline before changing code.

Two routines produce the same eight output bytes. Border markers make their execution regions easy to locate in VICE, but exact cycle conclusions should come from instruction/cycle measurement rather than visual width alone.

Record code size and measured execution cost before proposing an optimization.

**Why does a demo coder care?** Optimization without a measured constraint can waste both bytes and development time.

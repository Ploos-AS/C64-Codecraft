The appendices are references, not extra mandatory courses. Use them when a lesson, lab or production task needs a tool or lookup.

## Technical references
Later appendices should collect concise 6510/VIC-II/SID memory/register/cycle reference material, PAL/NTSC notes, PETSCII/screen-code notes and troubleshooting.

The lesson text remains the place where concepts are taught. An appendix answers “how do I use/check this?” without turning the main course into a tool manual.
